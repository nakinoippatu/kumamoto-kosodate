# 🍊 熊本市 子育て支援イベントカレンダー

熊本市内の子育て支援イベントを自動収集し、カレンダー形式で表示するWebサービスです。

🔗 **公開URL**: https://nakinoippatu.github.io/kumamoto-kosodate/

---

## 📌 概要

乳幼児・保護者向けのイベント情報を5系統のソースから毎朝自動取得し、GitHub Pages で公開します。

- **キーワード検索・フィルター・ソート**でイベントを絞り込み可能
- 予約が必要なイベントは「★」マークで識別
- カレンダービュー / リストビューを切替可能
- 取得失敗時は前回データのキャッシュで補完（サーバー障害対策）

---

kumamoto-kosodate/

## 📡 データソース（5系統・合計約200〜220件/月）

### A) 子育てナビ
- **URL**: https://www.kumamoto-kekkon-kosodate.jp
- **取得方法**: Playwright（JavaScript レンダリング対応）
- **内容**: 熊本市内の子育て講座・イベント全般（約27件）

### B) 総合子育て支援センター
- **URL**: https://www.city.kumamoto.jp/kiji0031482/index.html
- **取得方法**: Playwright（動的ページ）
- **内容**: 中央区本荘の支援センター主催イベント（月2〜4件）

### C) こども文化会館
- **URL**: https://www.kodomobunka.jp/event/
- **取得方法**: requests（静的HTML）
- **内容**: 乳幼児・保護者向けイベントに絞ってフィルタリング（月8〜12件）

### D) 各児童館（PDF解析）

pdfplumber を使って各施設の月次PDFカレンダーを解析します。

| 施設名 | PDF形式 |
|---|---|
| 幸田児童館 | 月〜日カレンダー形式 |
| 西部児童館 | 月〜土カレンダー形式 |
| 西原公園児童館 | リスト形式 |
| 花園児童館 | 21列カレンダー（表裏2枚） |
| 託麻児童館 | 月〜土カレンダー |
| 秋津児童館 | 花園と同形式（21列） |
| 五福児童室 | 動的ページからPDF取得 |
| 天明児童室 | 動的ページからPDF取得 |
| 大江児童室 | 動的ページからPDF取得 |
| 城南児童館 | Google Drive PDF（手動対応） |

### E) 子育て支援センター18施設（PDF解析）

熊本市の統括ページから18施設分のPDFを一括取得・解析します。

- **統括ページ**: https://www.city.kumamoto.jp/kiji00364201/index.html
- **対応施設**: 総合 / 白山 / 京塚 / イルカクラブ / ながみね / やまなみ / 画図 / 小島 / 池上 / 京町台 / 幸田 / さくらっこ / だいいち / 城南 / 植木 / 清水 / 西里 / あゆみ（約130〜160件）

各施設のPDF形式は多様で、以下の複数パーサーを自動判定して使い分けます。

| パーサー種別 | 対象例 |
|---|---|
| 7列カレンダー（標準形式） | 総合・白山・京塚・小島など |
| 17列カレンダー（京町台形式） | 京町台 |
| 5列週間形式（さくらっこ形式） | さくらっこ |
| ☆詳細ブロック＋カレンダー（幸田形式） | 幸田SS |
| やまびこだより形式（植木形式） | 植木 |
| word座標ベース（だいいち形式） | だいいち |
| お知らせ欄直接解析（あゆみ形式） | あゆみ |

## ⚙️ セットアップ（ローカル実行）

### 1. 依存パッケージのインストール

```bash
pip install requests beautifulsoup4 playwright pdfplumber lxml
playwright install chromium
```

### 2. スクレイピング実行

```bash
python scraper.py
```

`docs/events.json` と `docs/index.html` が自動更新されます。実行完了後、`docs/index.html` をブラウザで開けばローカル確認できます。

---

## 🤖 GitHub Actions 自動実行

`.github/workflows/scrape.yml` により、**毎朝7時（JST）** に自動実行されます。

```
スケジュール: 0 22 * * * (UTC) = 毎朝7:00 JST
```

実行フロー：

1. リポジトリをチェックアウト
2. Python 3.11・依存パッケージ・Playwright をセットアップ
3. `python scraper.py` を実行
4. `docs/events.json` と `docs/index.html` をコミット＆プッシュ

手動実行も可能（GitHub の Actions タブ → Run workflow）。

### サーバー障害時のキャッシュ補完

熊本市公式サーバーが一時的に 500/504 エラーを返した場合、取得できなかったソースの直前データを自動補完します。取得件数が 150件を下回ったときに補完が有効になります。

## ⚠️ 既知の制限・注意事項

- **スキャンPDF**（城南子育て支援センターなど）はテキスト抽出不可のため0件になることがあります。
- **PDFのレイアウト変更**があった場合、パーサーが0件を返すことがあります。その際は当リポジトリにIssueを立ててください。
- 掲載情報は各施設の公式資料に基づきますが、**最新情報・申込方法は必ず各施設に直接ご確認ください**。
